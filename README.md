# 💻 DevRoaster Terminal v1.0

> A self-aware terminal that crashes dramatically, judges you silently, and still lets you type `recover` like a hero.

Welcome to **DevRoaster** — a fake OS that takes itself way too seriously.

This is not just a terminal.
This is ✨ drama-driven engineering ✨

---

## 🚀 What Is This?

DevRoaster is an interactive CLI-style web app that:

* Simulates a developer terminal
* Accepts commands like a mini OS
* Triggers a full-screen animated SYSTEM FAILURE
* Moves input to bottom-right during crash
* Locks the system until `recover`
* Remembers crash count (yes, it keeps receipts 👀)

Basically:
You type → It reacts → Sometimes it panics → You fix it.

---

## 🎮 How To Use

Type commands in the terminal:

```
help
crash
recover
clear
stats
joke
```

### 🔥 Main Commands

| Command   | What It Does                           |
| --------- | -------------------------------------- |
| `help`    | Shows command list                     |
| `crash`   | Triggers full cinematic system failure |
| `recover` | Reboots the system                     |
| `stats`   | Shows total crash count                |
| `clear`   | Clears terminal                        |
| `joke`    | Random dev joke                        |

* Switch-case routing logic
